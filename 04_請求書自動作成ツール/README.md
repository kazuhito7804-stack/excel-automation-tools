# 請求書自動作成ツール

会社名・品目・単価・数量が並んだ一覧表Excelを読み込み、取引先ごとに体裁の整った請求書シートを自動生成するツールです。

## 解決する課題

複数の取引先へ請求書を発行する際、1社ずつ手作業でシートを作成すると時間がかかり、金額計算のミスも起こりがちです。このツールは、1つの一覧表から取引先ごとに自動で振り分け、金額・小計・消費税・合計まで正しく計算された請求書を一括で作成します。

## 主な機能

- 一覧表を会社名でグループ化し、取引先ごとに専用シートを自動作成
- 品目・単価・数量から金額を自動計算し、小計・消費税(10%)・合計金額まで算出(すべてExcel数式で計算するため、単価や数量を修正すると自動で再計算される)
- 罫線・見出しの色付け・列幅の自動調整など、見やすいレイアウトに整形
- A4用紙1ページに収まるよう印刷設定(用紙サイズ・余白・拡大縮小)を自動設定

## 使い方

1. `請求データ`フォルダの中の一覧表(フォーマット:会社名・品目・単価・数量の4列)に取引データを入力する
2. 以下を実行

```bash
python seikyusho.py
```

3. `seikyusho_kekka.xlsx`が生成され、取引先ごとの請求書シートが作成される

## サンプルデータ

`請求データ`フォルダに、5社(株式会社山田商事、田中商店、大山商会、佐藤工業株式会社、高崎工業)分のサンプルデータを同梱しています。

## 使用技術

- Python 3
- openpyxl
