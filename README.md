# Excel業務効率化ツール集

Python(openpyxl)を使って、Excelを使った日常業務を自動化するツールをまとめたリポジトリです。

35年間、市役所で文書・データ処理業務に携わってきた経験をもとに、実際の業務で発生しがちな課題(複数ファイルの集計、フォーマットの不統一など)を解決するツールを作成しています。

## 収録ツール

| No. | ツール名 | 解決する課題 |
|---|---|---|
| 01 | [売上集計ツール](./01_売上集計ツール) | 店舗ごと・月ごとに分かれた売上Excelファイルを、1つの集計表にまとめる |
| 02 | [勤怠集計ツール](./02_勤怠集計ツール) | 社員ごとの出退勤記録から、月間の総残業時間を自動計算する |
| 03 | [フォーマット統一ツール](./03_フォーマット統一ツール) | 会社ごとに列の並びがバラバラな顧客リストを、統一フォーマットにまとめる |
| 04 | [請求書自動作成ツール](./04_請求書自動作成ツール) | 会社名・品目・単価・数量の一覧表から、取引先ごとの請求書を自動作成する |

## 共通の技術スタック

- Python 3
- openpyxl(Excelファイルの読み書き)
- glob, os(複数ファイルの一括処理)

## 使い方

各フォルダの中に、ツール本体(`.py`)とサンプルデータが入っています。フォルダ内のREADMEに詳しい使い方を記載しています。

```bash
pip install openpyxl
python ツール名.py
```
