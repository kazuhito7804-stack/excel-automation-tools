# 送迎ルート最適化ツール

児童デイサービスなどの送迎業務を想定し、住所録から施設に近い順の訪問リストを自動計算するツールです。住所を緯度経度に変換して距離を算出し、近い順に並べ替えたリストをExcelに書き出します。

## 解決する課題

複数の訪問先がある送迎業務では、どの順番で回るのが効率的かを毎回手作業で考えるのは負担が大きく、慣れないスタッフだと判断にも時間がかかります。このツールは、住所録さえあれば施設からの距離を自動計算し、近い順の訪問リストをその場で作成します。

## 主な機能

- `geopy`(Nominatim)による住所→緯度経度変換(ジオコーディング)
- `geodesic`による施設からの直線距離計算と、近い順への自動並べ替え
- 「丁目」表記の有無に関わらず住所を正しく簡略化する処理(正規表現ベース)
- 検索対象を日本国内に限定し、都道府県省略時は自動補完して再検索することで、無料ジオコーディングサービス特有の誤マッチ(海外の同名地などへの誤ヒット)を防止
- 施設からの距離が現実的な範囲を超えた場合や住所が特定できない場合は、数値を書き込まず「要確認」として一覧に残す安全設計(送迎対象者の見落とし防止)

## 使い方

1. `住所録データ`フォルダの中の住所録Excel(フォーマット:名前・住所の2列)に訪問先を入力する
2. スクリプト冒頭の`FACILITY_ADDRESS`(施設住所)を実際の住所に書き換える
3. 以下を実行(初回のみ`pip install geopy openpyxl`が必要)

```bash
python juusho_saitekikatest.py
```

4. 同じExcelファイルに「送迎ルート結果」シートが追加され、距離が近い順の訪問リスト(および要確認一覧)が書き出される

## サンプルデータ

`住所録データ`フォルダに、丁目表記あり・なしが混在した5人分のサンプル住所録を同梱しています。

## 使用技術

- Python 3
- openpyxl
- geopy(Nominatim, geodesic)

## 工夫したポイント

実際にサンプルデータで動かしてみたところ、都道府県を省略した住所がまったく見当違いの場所(施設から2000km以上離れた地点)にマッチする不具合に遭遇しました。原因を調べ、検索を`country_codes="jp"`で日本国内に限定した上で、それでも距離が不自然な場合は都道府県を補って再検索するフォールバック処理を追加しています。それでも解決しない住所は結果を捨てずに「要確認」として必ず一覧に残すようにしており、精度と安全性の両方を意識した設計にしています。
