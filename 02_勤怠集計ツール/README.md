# 勤怠集計ツール

社員ごとの出勤・退勤時刻の記録から、月間の総残業時間を自動計算するツールです。

## 解決する課題

社員ごとに勤怠記録が別々のExcelファイルで管理されている場合、残業時間の集計を手計算で行うのは手間がかかり、ミスも起こりがちです。このツールは、出退勤時刻から自動的に残業時間を算出し、社員ごとに集計します。

## 主な機能

- フォルダ内の複数Excelファイルを自動で一括読み込み
- ファイル名(例:`田中_7月勤怠.xlsx`)から社員名・月を自動判定
- 出勤・退勤時刻から、休憩時間(1時間)を差し引いた実働時間を計算
- 定時(9:00〜17:00)を超えた分を残業時間として自動集計
- 早退等でマイナスになる場合は0として扱う(他の日の残業と相殺しない)
- 「社員別合計」シート(月をまたいでの合算)を自動生成

## 使い方

1. `勤怠データ`フォルダの中に、社員ごとの勤怠ファイルを入れる(フォーマット:日付・出勤時刻・退勤時刻の3列)
2. 以下を実行

```bash
python kintaisyukei_rensyu.py
```

3. `勤怠集計結果.xlsx`が生成される(集計結果・社員別合計の2シート構成)

## サンプルデータ

`勤怠データ`フォルダに、2名分(7月・10日分)のサンプルExcelファイルを同梱しています。

## 使用技術

- Python 3
- openpyxl
