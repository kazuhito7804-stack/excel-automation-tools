# 売上集計ツール

店舗ごと・月ごとに分かれた売上Excelファイルを自動で読み込み、1つの集計結果にまとめるツールです。

## 解決する課題

複数店舗・複数月の売上データが、店舗ごとに別々のExcelファイルで管理されている場合、手作業での集計は時間がかかり、ミスも起こりやすくなります。このツールは、フォルダ内のファイルを自動で読み込み、正確に集計します。

## 主な機能

- フォルダ内の複数Excelファイルを自動で一括読み込み
- ファイル名(例:`大阪支店_9月売上実績.xlsx`)から店舗名・月を自動判定
- 店舗×月×商品ごとの売上を自動集計
- 「店舗別合計」「商品別合計」シートを自動生成
- 売上金額のセルに関数(例:`=単価*数量`)が入っていても、計算済みの結果を正しく読み込む
- ファイル名が想定形式と異なるファイルは、処理を止めずにスキップし、最後にまとめて警告表示
- 出力ファイルは、見出し行を太字表示・列幅自動調整・金額を3桁区切り表示

## 使い方

1. `売上データ`フォルダの中に、店舗ごとの売上ファイルを入れる(フォーマット:商品名・単価・数量・売上金額の4列)
2. 以下を実行

```bash
python uriage_shukei.py
```

3. `集計結果.xlsx`が生成される(集計結果・店舗別合計・商品別合計の3シート構成)

## エラー時の挙動

ファイル名が「店舗名_○月売上実績.xlsx」の形式と異なるファイルが `売上データ` フォルダ内にあった場合、そのファイルはスキップされ、実行後に以下のような警告がターミナルに表示されます。処理自体は止まらず、他の正しいファイルの集計は最後まで実行されます。

```
⚠ 以下のファイルは、ファイル名が「店舗名_○月売上実績.xlsx」の形式と
  異なっていたため、集計されませんでした:
   - テストファイル.xlsx
```

## サンプルデータ

`売上データ`フォルダに、大阪支店・東京支店それぞれ9月・10月分のサンプルExcelファイルを同梱しています。

## 使用技術

- Python 3
- openpyxl

## テスト内容

以下の観点で動作確認済みです。

- 正常系:サンプル4ファイルでの集計結果が、手計算と一致することを確認
- 同一店舗・月・商品の行が複数ある場合、金額が正しく合算されること
- 売上金額のセルが関数(計算式)になっている場合でも、正しく数値を読み込めること
- ファイル名が想定形式と異なる場合、エラーで停止せず、警告を出しつつ他のファイルの集計を継続すること
